# Game_PocongSurvival
Game ini dibuat dalam rangka menyambut bulan ramadhan , yang mana di bulan yang suci dan penuh berkah bagi umat muslim ini justru membuat para setan ketakutan termasuk si ocong , si ocong adalah karakter utama di sini yang berperan sebagai pocong , dan ada satu karakter lagi yaitu pak ustad sebagai pemburu setan di bulan puasa .
